01 · What changed

The numbers before this were not measurements

Every row below was reproduced by running the code, not read off the source. Six are correctness defects in the proxies; six are defects in the harness that would have produced confident, wrong figures.

Verified by running each proxy against a live upstream and inspecting what it actually sent.

05 · Hot-path primitives

What the SIMD and asm actually bought

Criterion microbenchmarks, target-cpu=native on Apple M1. Each vector routine has a scalar twin and a differential test across every length from 0 to 200 bytes, because a silently wrong case-fold corrupts routing rather than crashing it.

The cycle counter reads cntvct_el0 on AArch64 and rdtsc on x86-64 through inline assembly. At these request rates two Instant::now() calls per request is a measurable cost sitting inside the number being measured.

06 · Reproducing this

Running the benchmark

Full instructions live in README.md at the repository root. These are the paths most people want.

Local sweep

Each candidate is launched as its own process on loopback.

# build every binary
cargo build --release

# smoke test: all three candidates, ~2 minutes
cargo run --release --bin lb-bench -- --all --quick

# the full Scenario 1 sweep (plan §8.1)
cargo run --release --bin lb-bench -- \
    --all --scenario throughput \
    --concurrency 100,1000,5000,10000,25000 \
    --payload-sizes 1k,64k,1m \
    --http h1,h2 \
    --duration 30s --warmup 15s

Verification gates

The four checks from plan §10, all currently passing.

cargo test --workspace --all-features
cargo clippy --workspace --all-targets \
    --all-features -- -D warnings
cargo fmt --all --check
RUSTFLAGS="-C target-cpu=native" cargo bench

Kubernetes, against Traefik

kind v0.32.0, node v1.31.6, Gateway API v1.2.1 — all pinned.

./scripts/setup_kind.sh
./scripts/build_and_load_images.sh
kubectl apply -f k8s/traefik/
kubectl apply -f k8s/rust-proxies/
kubectl apply -f k8s/routes/benchmark-httproute.yaml

cargo run --release --bin lb-bench -- \
    --mode k8s --all --churn-rate 50

Profile-guided optimization

Three passes; pass 2 drives load at the instrumented binary itself.

rustup component add llvm-tools   # version-matched
./scripts/build_pgo.sh lb-proxy-hyper
./scripts/build_bolt.sh lb-proxy-hyper   # Linux
